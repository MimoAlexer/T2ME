# Acknowledgements

T2ME is built on the Minecraft Forge toolchain and uses Mojang's official
1.20.1 mappings in development.

The project was informed by the goals of established performance and
pregeneration projects, including C2ME, Lithium, Canary, and Chunky. T2ME is a
clean-room implementation: it does not copy, embed, shade, or redistribute
their source code or binaries.

- Minecraft Forge provides the loader, event system, mappings toolchain, and
  supported chunk APIs used by T2ME.
- Canary supplies the Lithium-style Forge optimization role on deployments
  where it is installed.
- Chunky established a familiar operator workflow for long-running
  pregeneration tasks.
